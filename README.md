# Οι Ιστορίες που Έλεγε η Γιαγιά

## Μιχαήλ Σ. Μιχαλακόπουλος

Συλλογή 16 διηγημάτων που αντλούν θέματα από οικογενειακές αφηγήσεις, λαϊκούς μύθους, θρησκευτικά έθιμα και ιστορικά γεγονότα. Τα περισσότερα συνδέονται με τη λαϊκή παράδοση της Γορτυνίας, στην Αρκαδία.

## Διαβάστε τη συλλογή

### Συνοδευτικό υλικό

Η συλλογή περιλαμβάνει επίσης:

- Επίλογο.
- Γλωσσάρι των λέξεων της Γορτυνίας.
- Βιογραφικό σημείωμα του συγγραφέα.
- Ευχαριστίες.

Οι τέσσερις αυτές ενότητες είναι συνοδευτικό υλικό και δεν υπολογίζονται ως διηγήματα. Μπορείτε να τις βρείτε από την αρχική σελίδα της συλλογής.

## Σχετικά με τη συλλογή

Οι ιστορίες βασίζονται σε οικογενειακές μνήμες και προφορικές αφηγήσεις, τις οποίες ο συγγραφέας επεξεργάζεται λογοτεχνικά. Η συλλογή περιλαμβάνει επίσης κείμενα με θέματα από την ευρύτερη ελληνική ιστορία και παράδοση.

## Σχετικά με το αποθετήριο

Το αποθετήριο περιέχει τα αρχεία της ιστοσελίδας της συλλογής. Για ανάγνωση, χρησιμοποιήστε τους συνδέσμους που βρίσκονται στην αρχή αυτού του README.

Η αρχική σελίδα είναι το αρχείο `index.html`. Τα 16 διηγήματα αντιστοιχούν στα αρχεία `01.html` έως `16.html`. Υπάρχουν επίσης αρχεία για το συνοδευτικό υλικό και τον χάρτη ιστοτόπου.

Η ιστοσελίδα δημοσιεύεται μέσω GitHub Pages. Δεν έχουν ακόμη ελεγχθεί όλοι οι σύνδεσμοι και η εμφάνιση σε όλες τις συσκευές.
